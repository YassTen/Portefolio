# Personal Portfolio - Cybersecurity & Software Engineering

This repository contains the source code for my personal portfolio website. It showcases my security projects, full-stack web applications, technical reports, and resumes.

Live version: [https://yasssten.github.io/Portefolio/](https://yasssten.github.io/Portefolio/) *(Replace with your actual portfolio domain once deployed)*

## Tech Stack

- **Framework**: React.js (Vite)
- **Styling**: TailwindCSS (Modern Dark Mode & Glassmorphism UI)
- **Icons**: React Icons (FontAwesome, SimpleIcons, VSCode Icons)
- **Package Manager**: npm

## Key Features

- **Project Carousel**: Interactive display of key security and development projects with conditional links to GitHub source code and Notion documentation.
- **Dynamic CV Selector**: Interactive language selector dropdown in the navigation bar allowing users to download my resume in either French (FR) or English (EN).
- **Responsive Design**: Mobile-friendly navigation drawer and flexible grid layouts.

## Getting Started

To run this project locally, clone the repository and run the development server:

```bash
# Clone the repository
git clone https://github.com/YassTen/Portefolio.git

# Navigate to the project directory
cd Portefolio

# Install dependencies
npm install

# Run the local development server
npm run dev
```
